### 6.1 图的定义和基本术语

#### 6.1.1 图的定义

**图**（*Graph*）由两个集合 $V$ 和 $E$ 组成，记为 $G=(V,E)$

- $V$：有顶点的*有穷非空*集合

- $E$：$V$ 中顶点偶对的*有穷*集合，这些顶点偶对称为**边**

> ***顶点加边**，顶点不可为空*

$V(G)$ 和 $E(G)$ 通常分别表示为图 $G$ 的顶点集合和边集合，后者可以为空集

> 若 $E(G)$ 为空，则图 $G$ 只有顶点而没有边

若边集合为有向边的集合就称为有向图，为无向边的集合就称为无向图

#### 6.1.2 图的基本术语

##### 1. 子图

对于两个图 $G=(V,E)$ 和 $G'=(V',E')$

如果有 $V'\subseteq V$ 且 $E'\subseteq E$，则称 $G'$ 是 $G$ 的子图

##### 2. 无向完全图和有向完全图

- **完全图**：任意两顶点都有一条边相连的图

- **无向完全图**：具有 $\frac{n(n-1)}{2}$ 条边的无向图

- **有向完全图**：具有 $n(n-1)$ 条弧的有向图

##### 3. 稀疏图和稠密图

有**很少条边或弧**（如 $e<n\log_2n$）的图称为**稀疏图**，反之称为**稠密图**

##### 4. 权和网

给每条边标上有具体含义的数值，该数值就称为该边上的**权**；这种带权的图就称为**网**

> *权可以表示从一个顶点到另一个顶点的距离或耗费等*

##### 5. 邻接点

> **邻接**：*有边或弧相连的两个顶点之间的关系*

对于**无向图** $G$，如果图的边 $(v,v')\in E$，就称这两个顶点互为**邻接点**，即相邻接

边 $(v,v')$ **依附于**顶点 $v$ 和 $v'$，或者说边 $(v,v')$ 与顶点 $v$ 和 $v'$ **相关联**

##### 6. 度、入度和出度

- **度**：顶点 $v$ 的度是指和 $v$ **相关联的边的数目**，记为 $TD(v)$

- 对于有向图，度还分为入度和出度

  - **入度**：以顶点 v 为头的弧的数目，记为 $ID(v)$

  - **出度**：以顶点 v 为尾的弧的数目，记为 $OD(v)$

  > *有向图的度是入度和出度之和*，即
  >
  > $$
  > TD(v)=ID(v)+OD(v)
  > $$

一般地，一个有 $n$ 个顶点，$e$ 条边的图满足如下关系

$$
e=\frac{1}{2}\sum_{i=1}^nTD(v_i)
$$

即边数等于每个顶点的度的总和除以二

##### 7. 路径和路径长度

- **路径**：接续的边构成的顶点序列

- **路径长度**：一条路径上经过的边或弧的*数目*或*权值之和*（*对应无权图和有权图*）

##### 8. 回路或环

*第一个顶点*和*最后一个顶点*相同的路径

##### 9. 简单路径、简单回路或简单环

- **简单路径**：序列中顶点不重复出现的路径

- **简单回路或简单环**：*除第一个顶点和最后一个顶点*，其余顶点不重复出现的回路

##### 10. 连通、连通图和连通分量

- **连通**：两个顶点之间有路径

- **连通图**：任意两个顶点 $v_i,v_j\in V$，二者**都**相连通的图

- **连通分量**：*无向图*中的**极大连通子图**

  > ***每个相连通的部分即为连通分量***
  >
  > *或理解为，满足是连通子图的情况下尽可能添加新顶点和新边直到无可再加，最终形成的图*
  >
  > *类似的，**极小连通子图**可以理解为尽可能删除已有边直到无可再删*

##### 11. 强连通图和强连通分量

- **强连通**：两个顶点之间**都**有**通往另一方**的路径

- **强连通图**：在*有向图* $G$ 中，如果对于每一对 $v_i,v_j\in V$，$v_i\ne v_j$，从 $v_i$ 到 $v_j$ 和从 $v_j$ 到 $v_i$ 都存在路径，则称 $G$ 是强连通图

- **强连通分量**：*有向图*中的**极大强连通子图**

  > ***双向全连通***

##### 12. 连通图的生成树和生成森林

- **生成树**：包含无向图 $G$ **所有顶点**的极小连通子图（*即尽可能去除可去除的边*）

- **生成森林**：每个连通分量形成的生成树的集合

##### 13. 有向树和生成森林

- **有向树**：有一个顶点的入度为 0，其余顶点入度均为 1 的有向图

- **生成森林**：若干可有向树组成，含图中全部顶点，但只有足以构成若干柯不相交的有向树的弧

### 6.4 图的存储结构

#### 6.4.1 邻接矩阵

##### 1. 邻接矩阵表示法

> *建立一个顶点表记录顶点信息，与一个邻接矩阵存储各顶点之间的关系*

邻接矩阵表现为二维数组 $A[i][j]$，对于其值 $w_{i,j}$ 有

- 若为 `true/false` 表示是否有边

- 若为 `v/∞` 表示权值

  - $\infty$ 经常取一个远大于所有权值的不可能存在的数，用于占位表示为空

> $w_{i,j}$ 代表的就是 $<v_i,v_j>$ 或 $(v_i,v_j)\in E$

##### 2. 邻接矩阵表示法的优缺点

- 容易实现图的操作

- 判断是否有边，寻找邻接点

- 其占用存储空间只和顶点数目有关，与边数无关

  - 对于稀疏图仍有 $O(n^2)$ 的空间复杂度，造成大量资源浪费

#### 6.4.2 邻接表

##### 1. 邻接表表示法

对每个顶点建立一个*单链表*，把所有**与其有关的边的信息**连接起来，每个结点设为三个域：表头结点域（$v_i$），边结点域（*边信息*）和链域（*权值*）

$TD(v_i)=该单链表中链接的结点个数$

> 邻接表不唯一，因为链入顺序任意

###### 有向图的邻接表

链接*出边*或*入边*，若为前者

- 出度：单链表中链接的结点数

- 入度：邻接点域为 $v_i$ 的弧个数

- 度：$OD(v_i)+ID(v_i)$

##### 2. 采用邻接表表示法创建无向图（C++伪码）

```cpp
Status CreateUDG(ALGraph & G) {
    cin >> G.vexnum >> G.arcnum;
    for (i = 0; i < vexnum; i ++) {
        cin >> G.vexs[i];
        G.vertices[i].firstarc = NULL;
    }
    for (k = 0; k < G.arcnum; k ++) {
        cin >> v1 >> v2;
        i = LocateVex(G, v1); j = LocateVex(G, v2); // 确定结点在 G 中的位置
        
        p1 = new ArcNode(); // 申请边结点
        p1 -> adjvex = j;
        p1 -> nextarc = G.vertices[i].firstarc;  // 头插法插入该顶点的边结点链表
        G.vertices[i].firstarc = p1;
        
        p2 = new ArcNode(); // 申请边结点
        p2 -> adjvex = i;
        p2 -> nextarc = G.vertices[j].firstarc;
        G.vertices[j].firstarc = p2;
    }
    return OK;
}
```

##### 3. 邻接表表示法的优缺点

- 便于增加删除顶点

- 便于统计边的数目

- 空间效率高 $O(n+e)$，即点数+边数

- 不便于判断两个顶点之间是否有边

- 不便于计算有向图各个顶点的度

> *邻接矩阵更适用于稠密图，邻接表更适用于稀疏图*

### 6.5 图的遍历

#### 6.5.1 深度优先搜索

*类似于树的先序遍历，是树的先序遍历的推广*

> 增加辅助数组 `bool visited[n];` 来避免在回路中重复访问

##### 1. 深度优先搜索遍历的过程

- 访问指定的起始顶点

- 检查其邻接顶点

  - 若有未被访问的，任选一个访问

  - 否则，退回最近访问过的顶点

  直到与起始顶点连通的所有顶点都访问完毕

- 检查图中顶点

  - 若此时尚有顶点未被访问，再选其中一个顶点作为起始顶点访问

  - 反之意味着遍历结束

> 可以利用 `stack` 存储访问过的结点
>
> 访问该结点时将其入栈，访问完所有该节点的邻接结点后出栈
>
> 空栈即意味着遍历完毕
>
> ***当然，也可以直接利用递归函数实现***

##### 3. 深度优先搜索遍历的算法分析

- 邻接矩阵

- 邻接表

  - 遍历时间复杂度 $O(n+e)$

#### 6.5.2 广度优先搜索

*类似于树的按层次遍历*

> 和层序有关，故利用队列 `queue` 实现先进先出
>
> 同样要借助辅助数组 `bool visited[n];`

##### 1. 广度优先搜索遍历的过程

> ***出结点，入该结点的全部邻接点，全部邻接点访问结束再出上一个，直至全出***

##### 2. 广度优先搜索遍历的算法实现（C++伪码）

```cpp
void bfs(Graph G, int v) {
    visited[v] = true;
    initQueue(q);
    q.push(v);
    
    while (!q.empty) {
        q.pop();
        for (/* 此处遍历检查所有邻接点，依存储方式而异 */) {
            // 假设 w 是当前检查的邻接点
            if (!visited[w]) {
                visited[w] = true;
                q.push(w);
            }
        }
    }
}
```

##### 3. 广度优先搜索遍历的算法分析

*和深度优先搜索遍历结合*

- 无论 BFS 还是 DFS，遍历的时间复杂度只和存储方式有关

  - 邻接表 – $O(n+e)$

  - 邻接矩阵 – $O(n^2)$

- 而遍历的空间复杂度和遍历走过的路经有关

  - DFS – *栈的深度，也就是 DFS 生成树的深度*

  - BFS – *队列的长度，也就是 BFS 生成树的宽度*

### 6.6 图的应用

#### 6.6.1 最小生成树

**最小生成树**：当图为**有权图**时，使各边的权重之和最小的生成树

> 全称**最小代价生成树**（*Minimum Cost Spanning Tree*）
>
> 常用其简称**最小生成树**（*Minimum Spanning Tree*），即 ***MST***

**基本性质**：假设连通网 $N$ 中，$U$ 是顶点集 $V$ 的一个非空子集，若 $(u, v)$ 是一条具有最小权值的边，其中 $u\in U$、$v\in V-U$，则必存在一棵包含边 $(u, v)$ 的最小生成树

##### 1. Prim 算法

###### （1）Prim 算法的构造过程

- 以起始点一个点为初始集合

- 遍历邻接点，找到最小权的边加入集合

- 以新集合为整体，找到距该子图最小权的边加入集合

- 重复直到没有可加的边

***不断寻找符合基本性质条件的边加入新的树，直到无可再加***

###### （2）Prim 算法的实现

利用结构体类型存储从 u 到 v-u 最小花费的边

#### 6.6.4 关键路径

##### 1. AOV– 网

###### （1）事件 $v_i$ 的最早发生时间 $ve(i)$

###### （2）事件 $v_i$ 的最迟发生时间 $vl(i)$

###### （3）活动 $a_i\ =\ < v_j,v_k >$ 的最早开始时间 $e(i)$

###### （3）活动 $a_i\ =\ < v_j,v_k >$ 的最晚开始时间 $l(i)$

##### 2. 关键路径求解的过程

###### （1）对途中定点进行排序，在排序过程中按拓扑序列求出每个时间的最早发生时间 $ve(i)$

###### （2）按逆拓扑序列求出每个事件的最迟发生时间 $v(i)$

###### （3）求出每个活动 $a_i$ 的最早开始时间 $e(i)$

###### （4）求出每个活动 $a_i$ 的最晚开始时间 $l(i)$

###### （5）找出 $e(i)=l(i)$ 的活动 $a_i$，即关键活动

由关键活动形成的**由源点到汇点**的每一条路径就是关键路径，关键路径有可能不止一条
