# 字符和字符串处理的算法

---

#### 8.2.1 一维字符数组与字符串

C 语言中，系统会在字符串的末尾加上一个 **ASCII** 码值为 **0** 的字符作为结束标志（**表示为 `\0`**）

在程序中往往靠检验 `\0` 的位置来判断字符串是否结束

#### 8.2.2 C 语言中字符串的输入输出

利用 **%s** 控制字符串输入时，若遇到**空格符**，系统会将其**自动转为 `\0`**

因为 `\0` 是字符串结束的标志，所以只有空格符前输入的文本会被送入字符串

格式 **%m.ns** 可以控制**输出一个字符串的前 n 个字符，输出的总宽度为 m**

#### 8.2.3 字符串处理函数

- `strcmp`：比较时若出现不同字符，**以第一个不同字符的差为准**

  - *表现为类字典序*

- `strcpy`：使用时，字符数组必须够大到能容纳复制过来的字符串

##### 8.2.4.2 逐个处理字符串的字符

**手工复制的字符串应在末尾加上 `\0`**

### 8.4 扩展知识

#### 8.4.1 字符串的指针变量

```cpp
char* p;
// ⚠️ C++11 起采用这种赋值方法会触发 IOS C+ 警告
p = "I Love China!";

cout << *p << '\n';                   // 输出 "I"
for (int i = 0; i < strlen(p); i ++) 
    cout << *(p + i);                 // 输出 "I Love China!"
```

**指针变量 `p` 中保存的是字符串的首地址，不是整个字符串**

#### 8.4.2 指针数组

可用于处理多个字符串，使其更方便灵活

```cpp
// ⚠️ C++11 起采用这种赋值方法会触发 IOS C+ 警告
char* p[] = {"Basic", "C", "FORTRAN", "cobol"};
for (int i = 0; i < 4; i ++) 
	cout << *(p + i) << " ";  // 输出 "Basic C FORTRAN cobol "
```

上面声明了四个指针，指向分别四个字符串的首地址

这样声明，排序操作时**只需修改指针的指向**而不必逐一修改字符值，**移动指针也比移动字符串快得多**，既节省时间，亦节省空间
