##### 1. 中央处理器

> *主要含运算器和控制器*

*Central Processing Unit，中央处理单元*，简称 **CPU**

是一块超大规模的集成电路，是计算机的**运算及控制核心**

CPU 的数据来源是直接内存访问 *Direct Memory Acces*，简称 **DMA**

###### (1) 主要功能

*解释计算机指令*、*处理软件中的数据*

###### (2) 主要组成

- **算术逻辑单元**

  *Arithmetic Logic Unit*，即*运算器*，用于对数据进行**算术运算和逻辑运算**

- **控制器**

  *Control Unit*，从存储器中**存取指令**，并对指令进行**译码**，再照指令的要求按顺序向其他 CPU 内部元件**发出控制信号**，协调数据流动

- 寄存器

  *Registers*，是速度极快的*小型存储单元*，用于**临时存放数据、指令、地址和运算结果等信息**，包括

  - 程序计数器 *Program Counter*，*存储下一条指令的地址*

  - 指令寄存器 *Instruction Register*，*存储当前执行的指令*

  - 累加器 *Accumulator*，*存储计算的中间结果*

- 缓存

  *Cache*，CPU 内部的高速缓存 `L1,L2,L3` 可以用于存放常用数据以加快反问速度，减少于主存 RAM 之间的交互延迟

- 总线

  *Bus*，负责 CPU 内外部的数据传输，主要包括

  - 数据总线 *Data Bus*，传输数据

  - 地址总线 *Address Bus*，传输内存地址

  - 控制总线 *Control Bus*，传输控制信号

- 时钟单元

  *Clock Unit*，提供时钟信号，进而控制 CPU 各个部分的运行节奏，通常由**晶振**提供高精度的时钟频率

- 解码单元

  *Instruction Decoder*，负责解析指令并将其转换为 CPU 能执行的操作

这些组件的协同工作，使 CPU 能够完成指令**获取（Fetch）、解码（Decode）、执行（Execute）**的基本流程

##### 2. 存储器

*Memory*，是**记忆或暂存数据**的部件，分为两类

###### (1) 内存储器

有时也称*内存*，是**直接与 CPU 相联系**的存储设备，也是 PC 工作的基本

- 只读存储器 *Read Only Memory*，简称 **ROM**

- 随机读写存储器 *Random Access Memory*，简称 **RAM**

- 高速缓冲存储器 *Cache*

###### (2) 外存储器

是内存的延伸，可用于**长期存放数据**

当 CPU 需要执行其存储的某程序或访问数据时，**需要由外存调入内存供其访问**

> *软盘、硬盘、光碟、磁带等*

> 机械硬盘，*Hard Disk Drive*，简称 **HDD**
>
> 固态硬盘，*Solid State Drive*，简称 **SSD**

##### 3. 输入设备

*Input*，用于**将外部信息输入到存储设备中**以备使用

> *键盘、鼠标、光笔、图形扫描仪等*

##### 4. 输出设备

*Output*，用于**将运算结果、文件数据等信息输出到存储设备中**，显示器是计算机最主要的输出设备

> *显示器、打印机、绘图仪等*

##### 5. 其他

*网卡、调制解调器、声卡、显卡、视频卡等*，这些元件对现代计算机也是不可或缺的

#### 1.1.2 计算机软件系统

计算机软件可以根据其用途分为**系统软件**和**应用软件**两大类

##### 1. 系统软件

指**管理、控制、维护**计算机系统资源的程序集合，包括硬件资源和软件资源

**系统软件的核心是操作系统**，作为控制管理硬件及软件资源的系统软件，是用户与计算机进行交互的接口

> ###### 人机界面
>
> - 是人与计算机软硬件的*交互部分*
>
> - 是人与计算机之间传递信息的*媒介及窗口*
>
> - 是用户使用计算机系统的一种*操作环境*

不同的操作系统提供不同的人机界面，但无论哪种，其工作界面只有两种方式

- **命令行界面**，*Command Line Interface*，简称 **CLI**

- **窗口图形界面**，*Graphics User Interface*，简称 **GUI**

##### 2. 应用软件

除系统软件外的所有软件都称为应用软件

#### 1.1.3 计算机工作过程

计算机的自动工作依据了**冯 · 诺依曼**提出的 **”存储程序“** 原理：*事先将指挥其工作的程序存储起来，工作时 CPU 逐条执行程序中的语句来完成任务的执行*

其工作流程可描述为

1. 程序和程序运行所需的原始数据，在*控制器* 输入命令的作用下，通过*输入设备* 送入*存储器*

2. 程序指令在取指令命令的作用下逐条送入*控制器*

3. *控制器* 对指令进行译码，并按指令要求向*存储器* 和*运算器* 发出存取数命令和运算命令，经过*运算器* 计算并把计算结果存放到*存储器* 内

4. 在*控制器* 发出取数和输出命令的作用下，通过*输出设备* 输出结果

#### 1.1.4 计算机工作的特点

***计算机能存储程序而不仅是数据，从而自主完成一系列无需人工干预的操作，是计算机与其他运算工具最本质的区别***

##### 优点

- 运算快、存储能力强

- 工作不怕重复麻烦

##### 缺点

- 不能自主分析解决问题，***程序的本质仍然是人们分析问题后得到的解题方法***

- 计算机不可能灵活纠正程序中可能发生的错误
