# 分支结构算法及其实现

---

#### 4.1.2 逻辑运算和逻辑表达式

##### 德摩根定律

- `!(A && B) === (!A) || (!B)` – ***非 (A且B) 等价于 (非A) 或 (非B)***

- `!(A || B) === (!A) && (!B)` – ***非 (A或B) 等价于 (非A) 且 (非B)***

---

#### 4.7.2 条件运算符

条件运算符是 C 语言中*唯一一个* 三目运算符，**优先级高于赋值运算符**，可简化一些 `if` 语句的书写

但其**降低了程序的可读性**，不予提倡

---

#### 4.8.2 可读性

使用表达式的自然形式，把含有**否定**运算的条件**变成肯定**的，减少使用 “否定” 条件

> ```cpp
> if (!(a<N)||!(a>=M))    // ❌
> ```
>
> ```cpp
> if ((a>=N) || (a<M))    // ✅
> ```

将**整型变量**与**零值**用 `==` 或 `!=` 比较，不要省略

> ###### `int value = 0; cin >> value;`
>
> ```cpp
> if (!value)             // ❌
> ```
>
> ```cpp
> if (value == 0)         // ✅
> ```

#### 4.8.3 质量保证

***不可将实型变量用 `==` 或 `!=` 与任何数字比较，应设法转换为 `>=` 或 `<=` 形式***

> ###### `double x; cin >> x;`
>
> ```cpp
> if (x == 0.0).          // ❌
> ```
>
> ```cpp
> constexpr double EPSILON = 1e-9;
> if (fabs(x) <= EPSION)  // ✅
> ```
