# 数组

---

#### 7.1.2 一维数组的定义和引用

数组元素在内存中是**一组连续的存储单元**，系统为这组存储单元分配了名字，存储相同类型的数据

#### 7.1.4 数组名做函数的参数

**数组名实际上是数组第一个元素的地址**，即数组的首地址

**格式控制符 %p** 可以以十六进制形式打印内存地址

```cpp
printf("%p", a);
// 等同于
printf("%p", &a[0]);
```

**参数传递时**，系统传递的不是实参数组中个元素的值，而是实参数组名所代表的**实参数组的首地址**

数组名作为参数属于参数传递方式中的地址传递，**形参变化会影响实参**

C 语言中**允许形参数组不定义元素的个数**，其大小**默认与实参数组相同**，但其他任意情况都必须定义数组大小

#### 7.1.5 排序和查找算法

**排序的基本思想**：把无序数列中的数据*逐一转换* 到有序序列

##### 7.1.5.1 选择法排序

基本就是手工排序的模拟，*每次找到最小值放到首位*，时间复杂度 $O(n^2)$

选择法优化空间很大，其优化方式也很多，其中堆 `priority_queue` 能加速达到 $O(n\ log\ n)$ 的复杂度

```cpp
priority_queue<int, vector<int>, greater<int>> pq(a.begin(), a.end());
for (int i = 0; i < a.size(); i++) {
    a[i] = pq.top(); pq.pop();
}
```

##### 7.1.5.2 冒泡法排序

对**相邻两个数据**进行比较，若其大小关系**与排序要求相反，则把它们互换**，重复 $n-1$ 次，平均时间复杂度 $O(n^2)$

**优化：若某次应交换但未发生实际交换，则意味着排序已经完成，可在此时跳出循环**

优化后的最优时间复杂度可以接近 $O(n)$

```cpp
// 第一层循环只需要满足重复 n-1 次即可，i 的值没有意义
// 因此可以写成其他任意满足 n-1 次的形式，只是需要相对应地更改 j 的最大范围
// 其中 i 取 [1,n)，j 取 [0,n-i) 可读性最好，7.3.3的指针例子就用的这一种
for (int i = 0; i < a.size() - 1; i ++) {
	bool flag = false;
    for (int j = 0; j < a.size() - 1 - i; j ++) {
       	if (a[j] > a[j + 1]) {
       		swap(a[j], a[j + 1]);
       		flag = true;	
       	}
    }
    if (!flag) break;
}
```

*冒泡排序的平均时间复杂度虽然和选择排序差不多，但对已经近似有序的数据优化十分明显，越是近似有序越能接近最优时间复杂度*

#### 7.2.4 二维数组名做函数的参数

在被调函数对二位形参数组定义时**可缺省第一维的大小说明**，但不能缺省第二维

更高维数组亦如此，仅第一维大小可缺省

和一维数组 `a[i]` 可以退化成 `*(a+i)` 同理，数组名已经提供了地址信息，至于第一维移动多少位函数并不需要关心，***这也意味着它可以访问到数组没有定义的非法内存***

### 7.3 扩展知识

#### 7.3.1 数组的初始化

- `int a[6] = {0}; // ✅`  `int a[6] = {}; // ❌`

  数组赋初值时，**所提供初值数目不足其大小时其余自动取 0，但无值只会保留原址数据**

- `int a[2][3] = {{1,2,3,}, {4,5,6}};` 和 `int a[2][3] = {1, 2, 3, 4, 5, 6};`

  两者作用相同，只是前者会更清晰

多维数组也可以用初值缺省的方式只对部分量赋值，其余自动取 0

```cpp
int a[2][3] = {
  {1, 2}, 
  {4}  
};  // 如三角矩阵赋初值
```

#### 7.3.2 一维数组的指针变量

`int array[N];` 中，**array 本质已经是指针**，因此可以通过

- `int* p;`

- `p = array;` 或 `p = &array[0];`

来建立指针和数组之间的指向关系

`array[i]` 和 `*(array+i)` 等价，前者的**下标法更简单直观**，后者的**指针法能降低程序运行内存，加快速度**

***利用指针法逐一访问元素时，应记得在使用完成后将指针复位***

```cpp
p = array;
for (int i = 0; i < N; i ++) scanf("%d", p ++);
p = array;        // 复位！！！
for (int i = 0; i < N; i ++) printf("%d", *(p ++));
```

同一数组内执行 `p2 - p1` 可以**快速得出两元素间的元素个数**

#### 7.3.3 一维数组指针做函数的参数

***实参和形参的形式除了是数组名之外，还可以是数组的指针变量***

```cpp
void bubbleSort(int* p, int n) {
    for (int i = 1; i < n; i ++) {
        for (int j = 0; j < n - i; j ++) {
            if (*(p+j) > *(p+j+1)) {
                swap(*(p+j), *(p+j+1));
            }
        }
    }
}
// 中间略，下文为 vector 数组用法，右侧为普通数组用法
int* p = a.begin();          // int* p = a;
bubbleSort(p, a.size());     // bubbleSort(p, N);
```
