# 循环结构算法及其实现

---

#### 5.1.2 C 语言中的 while 语句

C 语言中的特殊语句，**空语句**，仅由一个**分号** `;` 组成，应避免在书写时无意写出

##### 5.1.4.2 寻找规律的不定数循环

**不定数循环**：需要程序员在问题中*寻找循环的规律*，并由此*控制循环*

##### 5.1.5.2 变量迭代的方法

**迭代**：**不断**用变量的**旧值递推新值**的过程

*边读入边更新，这样的动态更新结构是其常见的性能优化手段*

---

#### 5.2.2 算法的健壮性

**健壮性**：对于规范要求意外的输入能够予以判断，并能有合理的处理方式

设计算法时，不能只考虑符合规范下的数据，即**正常情况下的处理**；更需要考虑的是**异常处理**。必须对数据的**有效性**进行**检验**，建立内部的保护机制

---

#### 5.4.1 自顶向下、逐步求精的设计方法

***先进行整体设计，然后再依次进行下一层的设计，逐步地实现精细化***

该方法符合人们解决问题的普遍规律，先全局后局部、先整体后细节开发出的程序具有清晰的层次结构，程序的可读性好

先搭建解决问题的顶层，再对顶层中未解决的部分求精，最后由求精的结果填充顶层

#### 5.4.2 循环的嵌套

绝大多数情况下，二重及以下的循环足以解决问题

超过三层的循环不仅增加程序阅读理解的困难，而且往往给程序的调试带来麻烦

> **吐槽**
>
> 二重本身的调试就已经够麻烦了，无法线性表示意味着需要时时刻刻翻动
>
> 二重以上的结构由于过于抽象不适合理解，这与拓扑学的观点不谋而合

#### 5.4.3 for 循环结构与穷举法

**穷举法的基本思想**：*一一列举出各种可能出现的情况，并判断哪一种是符合要求的*

也许很多人不欣赏这种算法，但这种方法确实很重要。许多科学界令人感兴趣的问题在计算机上除了 “死算” 没有更好的算法，正是因为尚缺乏相关研究资料才需要计算机的运算速度来模拟

---

#### 5.5.2 for 循环的灵活使用

从编程规范上来讲，**尽量避免使用技巧性过强的 for 语句**，不要因滥施技巧而使程序变得晦涩难懂

#### 5.5.4 枚举类型

作为一个原则，程序中**除 0、1 外**的常数**都应为其分配变量名**。这有助于代码理解，也便于日后修改

**枚举（enum）**是一个具有有限个整型符号常量的集合，定义形如

```cpp
enum weekday {
    Sun = 0, Mon = 1, Tue = 2, Wed = 3, Thu = 4, Fri = 5, Sat = 6  
};
```

虽然 `#define` 也能完成类似的工作~~（用这玩意是凑行数吗）~~，但**使用宏进行编程是一种比较危险的方式**，因为宏在背地里会改变程序的语法结构

*多用枚举，少定义宏*

---

#### 5.6.3 提高效率

为**减少 CPU 切入循环的次数**，在多重循环中，**应把最忙的循环放在最内层**

```cpp
for (int row = 1; row <= 100; row ++)
    for (int col = 1; col <= 5; col ++)    // ❌
```

```cpp
for (int col = 1; col <= 5; col ++)
    for (int row = 1; row <= 100; row ++)  // ✅
```
